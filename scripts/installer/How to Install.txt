UnZip for macOS
===============

Free for anyone. No account, no license key, no paid permission.

Requires macOS 14 or later. Works on Apple Silicon and Intel.

Install from the disk image
---------------------------
1. Drag UnZip into the Applications folder.
2. Open UnZip from Applications (or Spotlight).
3. If macOS says the app cannot be opened, Control-click UnZip
   and choose Open, then click Open again.

Install from the package
------------------------
Double-click the .pkg in this folder and follow the steps.
There is no license to accept.
The app is installed in /Applications.

After install
-------------
Right-click a folder or file in Finder → Services → Zip with UnZip.

Optional (RAR / 7Z extract):
  brew install unar p7zip

Optional (VP9 video picture):
  install VLC from https://www.videolan.org/vlc/
